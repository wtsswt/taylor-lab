# 泰勒逼近

交互式泰勒展开可视化：任意展开点、任意阶数，附误差曲线与收敛边界。

在线：<https://wtsswt.github.io/taylor-lab/>

## 功能

- **六个基本展开**：eˣ、sin x、cos x、ln(1+x)、(1+x)^α、1/(1−x)
- **任意展开点**：x₀ 可调，也可直接在图上点击设定；滑块范围随函数定义域变化
- **阶数 0–80**：前 10 阶逐阶，之后步长 2 → 4 → 8
- **系数写成表达式**：优先还原为简洁分数并按 `xⁿ/n!` 的教材形式排版；eˣ / sin / cos 在 x₀ ≠ 0 时系数为无理数，写成 `sin 1`、`e²` 这类符号形式，写不出的才退回数值
- **误差图**：独立面板用对数刻度画 |f(x) − Pₙ(x)|，可直接看出误差在展开点最小、向外指数增长
- **收敛边界**：ln、(1+x)^α、1/(1−x) 在 x₀ ± R 处标出收敛半径，边界外多项式必然跑飞
- **视窗按函数自适应**：sin / cos 铺开 ±7.5 看两个多周期，ln 从 −1.15 拉到 8
- **悬停读数**：显示该点的 f(x)、Pₙ(x) 与误差
- **链接可复现**：当前配置写在 URL 里（如 `#f=ln&x0=2&n=4`）

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击图上任意位置 | 把展开点移到那里（吸附到 0.1） |
| 滚轮 / 双指捏合 | 以光标或两指中点为锚缩放 x 轴 |
| 拖动 | 平移 |
| 右下角 ＋ − ⟲ | 缩放与复位 |
| ← / → | 阶数减一档 / 加一档 |
| 双击 | 复位到该函数的默认视窗 |

## 排版

多项式用 HTML + CSS 排真分数，不依赖 MathJax。系数先做连分数有理逼近，命中则写成上下分数；若系数恰为 1/k!（eˣ、sin、cos 在 x₀ = 0 的情形）则排成 `x³/3!` 这类教材写法，ln(1+x) 在 x₀ = 0 时排成 `x²/2`、`x³/3`（按函数判断而非数值巧合）。分母上限 9999 且逼近误差须 < 1e-10，超出即视为无理系数直接给数值，不硬凑假精度。

每一项（含运算符）是不可拆的 nowrap 块，换行只发生在运算符之前，不会出现「减号在行尾」。
