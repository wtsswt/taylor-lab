# 泰勒逼近 · 可视化实验室

一个单文件的交互式泰勒展开可视化页面。没有依赖、没有构建步骤，打开就能用。

## 做了什么

- **六个基本展开**：eˣ、sin x、cos x、ln(1+x)、(1+x)^α、1/(1−x)
- **任意展开点**：x₀ 可调，直接在图上点击也能设；滑块范围随函数定义域变化
- **阶数 0–80**：前 10 阶逐阶，之后步长 2 → 4 → 8，越往后越粗
- **系数写成表达式**：优先还原成简洁分数并按 `xⁿ/n!` 的教材形式排版，还原不了的无理系数才退回数值
- **误差图**：下方独立面板，对数刻度画 |f(x) − Pₙ(x)|，能一眼看出误差在展开点最小、向外指数增长
- **收敛边界**：ln、(1+x)^α、1/(1−x) 会在 x₀ ± R 处标出收敛半径，边界外多项式必然跑飞
- **视窗按函数自适应**：sin/cos 默认铺开 ±7.5 看够两个多周期，ln 从 −1.15 拉到 8
- **悬停读数**：鼠标移到图上显示该点的 f(x)、Pₙ(x) 与误差
- **链接可复现**：当前配置写在 URL 里（`#f=ln&x0=2&n=4`），可以把某个“翻车现场”直接发给别人

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击图上任意位置 | 把展开点移到那里（吸附到 0.1） |
| 滚轮 / 双指捏合 | 以光标或两指中点为锚缩放 x 轴 |
| 拖动 | 平移 |
| 右下角 ＋ − ⟲ | 缩放与复位（触屏友好） |
| ← / → | 阶数减一档 / 加一档 |
| 双击 | 复位到该函数的默认视窗 |

## 排版说明

多项式用 HTML + CSS 排真分数，不依赖 MathJax 等外部库。系数先做连分数有理逼近，命中的写成上下分数；若系数恰为 1/k!（eˣ、sin、cos 在 x₀=0 的主角情形），则排成 `x³/3!` 这种教材标准写法。分母超过五万的分数不硬凑，直接给数值。

## 为什么好玩

把 n 从 0 拖到 80，看多项式一段一段咬住原函数；再把 x₀ 拖到收敛半径边缘，看逼近区间怎么被挤成一条缝。这两件事光看公式看不出来。
