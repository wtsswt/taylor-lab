# 泰勒逼近 · 可视化实验室

一个单文件的交互式泰勒展开可视化页面。没有依赖、没有构建步骤，打开就能用。

## 做了什么

- **六个基本展开**：eˣ、sin x、cos x、ln(1+x)、(1+x)^α、1/(1−x)
- **任意展开点**：x₀ 可调，直接在图上点击也能设；滑块范围随函数定义域变化
- **任意阶数**：n = 0 ~ 12，多项式用 Horner 法求值
- **系数按解析式算**：不是数值微分，任意 x₀ 都精确到机器精度
- **误差图**：下方独立面板，对数刻度画 |f(x) − Pₙ(x)|，能一眼看出误差在展开点最小、向外指数增长
- **收敛边界**：ln、(1+x)^α、1/(1−x) 会在 x₀ ± R 处标出收敛半径，边界外多项式必然跑飞
- **悬停读数**：鼠标移到图上显示该点的 f(x)、Pₙ(x) 与误差
- **链接可复现**：当前配置写在 URL 里（`#f=ln&x0=1&n=3`），可以直接把某个"翻车现场"发给别人

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击图上任意位置 | 把展开点移到那里（吸附到 0.1） |
| 滚轮 | 以光标为中心缩放 x 轴 |
| 拖动 | 平移 |
| ← / → | 阶数减一 / 加一 |
| 双击 | 复位视窗 |

## 为什么好玩

把 n 从 0 拖到 12，看多项式一段一段咬住原函数；再把 x₀ 拖到收敛半径边缘，看逼近区间怎么被挤成一条缝。这两件事光看公式看不出来。
